Range               Size            Device
==========================================================
$0000-$07FF         $0800           2KB Internal RAM
----------------------------------------------------------
$0800-$0FFF         $0800
$1000-$17FF         $0800           Mirrors of $0000-$07FF        
$1800-$1FFF         $0800
----------------------------------------------------------
$2000-$2007         $0008           8 PPU registers
----------------------------------------------------------
$2008-$200F         $0008
$2010-$2017         $0008
[...]               [...]           Mirrors of $2000-$2007
$3FF0-$3FF7         $0008
$3FF8-$3FFF         $0008
----------------------------------------------------------
$4000-$4017         $0018           APU & IO registers
----------------------------------------------------------
$4018-$401F         $0008           APU & IO functionality 
                                    (Normally disabled)
----------------------------------------------------------
$4020-$FFFF         $BFE0           Unmapped (available for 
                                    cartridge use)
----------------------------------------------------------


Notes:
* $6000-$7FFF is normally used for cartridge RAM (PRG-RAM).
* $8000-$FFFF is normally used for cartridge ROM (PRG-ROM) and mapper registers.
